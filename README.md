# Typing Game

A browser-based typing speed game. Type the displayed passage while following the highlighted keyboard keys, and track your speed and accuracy during a 60-second round.

## Run Locally

No dependencies or build step are required.
Just Open "Index.html"

## Play

1. Enter your email when prompted. It is used to label your locally saved score.
2. Click the typing input to begin. A three-second countdown starts the round.
3. Type the displayed words. The on-screen keyboard highlights the next letter.
4. Watch your words per minute, errors, accuracy, and remaining time.
5. Click outside the input to pause; click it again to resume after a countdown.

Scores are stored in your browser's local storage and are not sent to a server. Clearing the browser's site data removes them.
